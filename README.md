## ✦ О проекте

**Style Userbot** — Telegram-юзербот на [Telethon](https://github.com/LonamiWebs/Telethon), который автоматически меняет стиль твоих исходящих сообщений.

Ты пишешь:

```text
Привет, как дела?
```

А собеседник получает:

```text
приветик, как дела? кавай~
```

Никаких нейросетей, API-ключей и расходов на токены. Всё работает локально по заданным правилам: замена слов, регулярные выражения и немного случайности.

> **EN:** A Telethon-based Telegram userbot that rewrites your own outgoing messages in a chosen style (femboy, yandere, tsundere, gopnik, depressive, business, gremlin, formal, uwu, static, glitch, oldpc). Russian-language text only. Rule-based, no AI/API keys required.

## ✦ Возможности

Бот редактирует сообщение сразу после отправки. Режим переключается командой прямо в чате.

### Доступные стили

| Режим | Команды | Пример |
|:--|:--|:--|
| 🎀 Фембой | `.soft` `.cute` `.max` | приветик, как дела? кавай~ |
| 💗 Яндере | `.yandere` | приветик~ ♡ ты ведь ответишь мне, да? ♡ |
| 💢 Цундере | `.tsundere` | п-привет... чего тебе? ...б-бака! |
| 🧢 Гопник | `.gopnik` | здарова! купи газява и хрумки, в натуре |
| 🌧️ Депрессивный | `.depressive` | привет... ну... нормально, наверное... |
| 💼 Деловой | `.business` | Добрый день. Прошу подтвердить. |
| 😈 Хаотичный | `.gremlin` | ЧТО ТЫ ДЕЛАЕШЬ АХАХАХА >:D |
| 🎩 Сверхофициальный | `.formal` | Здравствуйте. Рад приветствовать вас. |
| 🌸 Анимешный | `.uwu` | я тя поняль uwu 👉👈 |
| 📺 Помехи | `.static` | кₐк дₑлₐ? ░▒▓ .. |
| 👾 Глитч | `.glitch` | пппприиивеет... ошиbка_404 |
| 🖥️ Старый компьютер | `.oldpc` | C:\\USER> привет_ |

### Дополнительные команды

| Команда | Описание |
|:--|:--|
| `.on` / `.off` | Включить / выключить стиль |
| `.fem` | Женские формы глаголов (`я сделал` → `я сделала`) |
| `.status` | Показать текущие настройки на пару секунд |
| `!текст` | Отправить сообщение без обработки |

**Особенности команд:**
- Работают в любом чате, в том числе в «Избранном».
- Сообщение с командой автоматически удаляется.
- Режим можно менять прямо во время общения.

### Что пропускается

Не обрабатываются:
- Фото, файлы и стикеры.
- Сообщения с форматированием или ссылками.
- Команды ботов (`/...`).

## ✦ Установка

**Требования:**
- Python 3.9 или новее.
- Telegram-аккаунт.
- API ID и API Hash.

### 01. Клонирование репозитория

```bash
git clone https://github.com/<твой_ник>/<репозиторий>.git
cd <репозиторий>
pip install -r requirements.txt
```

### 02. Получение API ID и API Hash

1. Открой [my.telegram.org](https://my.telegram.org).
2. Войди по номеру телефона (код придёт в приложение Telegram).
3. Выбери **API development tools**.
4. Создай приложение (название любое, платформа Desktop).
5. Скопируй `api_id` и `api_hash`.

### 03. Настройка API

Открой `style_userbot.py` и впиши свои данные:

```python
API_ID = 12345678
API_HASH = "твой_api_hash"
```

Либо задай переменные окружения `API_ID` и `API_HASH`.

### 04. Настройка прокси (необязательно)

Если Telegram работает без прокси, **ничего менять не нужно**: оставь `PROXY_HOST` пустым, и скрипт подключится напрямую.

Для MTProto-прокси укажи:

```python
PROXY_HOST = "адрес_прокси"
PROXY_PORT = 443
PROXY_SECRET = "секрет_из_32_символов"
```

Эти значения тоже можно задать переменными окружения: `PROXY_HOST`, `PROXY_PORT`, `PROXY_SECRET`.

**Обрати внимание:**
- Секрет должен быть из 32 символов.
- Если он начинается с `dd`, убери эти две буквы.
- Fake-TLS секреты (начинаются с `ee`) в Telethon не поддерживаются.
- Для SOCKS5 в файле есть закомментированный вариант. Нужен `pip install python-socks[asyncio]`.

### 05. Запуск

```bash
python style_userbot.py
```

При первом запуске введи **свой номер телефона**, а не токен бота, и код из Telegram.

В папке появится файл `style.session`.

## ✦ Вход по QR-коду

Если код из Telegram не приходит, можно использовать QR-авторизацию.

Установи зависимость:

```bash
pip install qrcode[pil]
```

Запусти:

```bash
python qr_login.py
```

Откроется изображение с QR-кодом.

На телефоне:

**Настройки → Устройства → Подключить устройство**

Наведи камеру на QR-код.

Скрипт использует настройки API и прокси из `style_userbot.py`.

## ✦ Частые проблемы

| Проблема | Решение |
|:--|:--|
| `Впиши свои API_ID и API_HASH` | Данные не вписаны или файл не сохранён |
| `TimeoutError` / `Server closed the connection` | Telegram недоступен: включи VPN на всём устройстве или настрой прокси |
| Команды ничего не делают | Скрипт вошёл как бот вместо пользователя. Удали `style.session` и войди по номеру |
| `database is locked` / `AuthKeyDuplicatedError` | Один файл `.session` используется несколькими запущенными скриптами. Смени имя сессии в `TelegramClient("...")` |
| `ModuleNotFoundError: style_core` | Файлы лежат в разных папках или названы по-другому |
| Код не приходит | Проверь чат «Telegram» внутри приложения или используй `qr_login.py` |

## ✦ Безопасность

> [!CAUTION]
> Файл `.session` предоставляет полный доступ к авторизованному Telegram-аккаунту. Не публикуй его и не передавай другим людям.

**Никогда не коммить:**

- `API_HASH`
- Файлы `*.session`
- Токены Telegram-ботов
- Секреты прокси
- QR-коды и коды авторизации

Перед `git push` проверь, что в `style_userbot.py` стоят заглушки вместо личных данных.

Если токен или ключ попали в публичный репозиторий:
1. Пересоздай токен бота через `/revoke` в @BotFather.
2. Заверши подозрительные сессии через **Настройки → Устройства** в Telegram.
3. Не используй повторно скомпрометированные секреты.

Никому не отправляй QR-коды и коды входа.

## ✦ Дисклеймер

Юзерботы находятся в серой зоне правил Telegram.

Проект рассчитан на личное использование и редактирование собственных сообщений. Не используй его для спама и массовых рассылок: за это аккаунты могут блокировать.

Автор не несёт ответственности за блокировки и последствия использования.

Режимы вроде яндере и цундере отправляют сообщения реальным людям от твоего имени, поэтому используй их там, где тебя правильно поймут.

## ✦ Настройка стилей

Все фразы и вероятности находятся в `style_core.py`.

| Переменная | Назначение |
|:--|:--|
| `PRESETS` | Частота срабатывания эффектов (от 0 до 1) |
| `EMOTICONS` | Текстовые смайлики |
| `EMOJIS` | Эмодзи |
| `ACTIONS` | Действия |
| `FILLERS` | Дополнительные вставки |
| `SWAPS` | Основные замены слов |
| `GOPNIK_SWAPS` | Замены для гопник-стиля |
| `BUSINESS_SWAPS` | Замены для делового стиля |
| `FORMAL_SWAPS` | Замены для сверхофициального стиля |
| `UWU_SWAPS` | Замены для анимешного стиля |
| `GREMLIN_END` | Концовки хаотичного стиля |
| `STATIC_END` | Помехи в конце сообщения (стиль static) |
| `GLITCH_END` | Концовки глитч-стиля |
| `OLDPC_PREFIXES` | Приглашения командной строки (стиль oldpc) |
| `YANDERE_END` | Концовки яндере-стиля |
| `TSUNDERE_END` | Концовки цундере-стиля |
| `DEPRESSIVE_END` | Концовки депрессивного стиля |

Вероятности в `PRESETS` задаются числами от `0` до `1`.
