## ✦ О проекте

**Style Userbot** — набор инструментов для Telegram, который меняет стиль твоих исходящих сообщений. Проект включает основной userbot на [Telethon](https://github.com/LonamiWebs/Telethon), отдельные плагины и версии обычного Telegram-бота.

Ты пишешь:

```text
Привет, как дела?
```

А собеседник получает, например:

```text
приветик, как дела? кавай~
```

Основные стили работают локально: без нейросетей, API-ключей и расходов на токены.

> **EN:** Style Userbot is a collection of Telegram tools for transforming your outgoing messages with different text styles. The core userbot is powered by Telethon; style processing is rule-based and does not require AI or API keys.

## ✦ Возможности

Основной userbot редактирует собственное сообщение после отправки. Режим можно переключать командами прямо в чате.

### Доступные стили

| Режим | Команды | Пример |
|:--|:--|:--|
| 🎀 Фембой | `.soft` `.cute` `.max` | приветик, как дела? кавай~ |
| 💗 Яндере | `.yandere` | приветик~ ♡ ты ведь ответишь мне, да? ♡ |
| 💢 Цундере | `.tsundere` | п-привет... чего тебе? ...б-бака! |
| 🧢 Гопник | `.gopnik` | здарова! в натуре |
| 🌧️ Депрессивный | `.depressive` | привет... ну... нормально, наверное... |
| 💼 Деловой | `.business` | Добрый день. Прошу подтвердить. |
| 😈 Хаотичный | `.gremlin` | ЧТО ТЫ ДЕЛАЕШЬ АХАХАХА >:D |
| 🎩 Сверхофициальный | `.formal` | Здравствуйте. Рад приветствовать вас. |
| 🌸 Анимешный | `.uwu` | я тя поняль uwu 👉👈 |
| 📺 Помехи | `.static` | кₐк дₑлₐ? ░▒▓ .. |
| 👾 Глитч | `.glitch` | пппприиивеет... ошиbка_404 |
| 🖥️ Старый компьютер | `.oldpc` | C:\\USER> привет_ |
| 📰 Срочные новости | `.news` | СРОЧНО: пользователь написал привет |
| 🌐 Старый интернет | `.oldnet` | привет!!! *_* |
| 🔁 Реверс | `.reverse` | !тевирП |

### Команды основного userbot

| Команда | Описание |
|:--|:--|
| `.on` / `.off` | Включить / выключить обработку |
| `.fem` | Переключить женские формы глаголов |
| `.status` | Показать текущие настройки |
| `!текст` | Отправить сообщение без обработки |

Команды управления отправляются в чат и обрабатываются самим userbot. Необработанные сообщения, команды и неподдерживаемые типы контента пропускаются.

## ✦ Отдельные плагины

Плагины устанавливаются отдельно от основного userbot. Они не заменяют `style_userbot.py` и могут иметь собственные настройки.

### 🎲 Random Style

Отдельный плагин, который случайным образом выбирает стиль для исходящего сообщения.

**Что умеет:**
- Выбирать случайный стиль из набора поддерживаемых режимов.
- Не повторять предыдущий стиль подряд, если включена соответствующая настройка.
- Включать и выключать обработку через настройки плагина.
- Поддерживать исключение сообщений с префиксом `!`.
- Пропускать команды и сообщения, которые не подходят для обработки.

**Настройки:**

| Настройка | Описание |
|:--|:--|
| Enabled | Включает или выключает Random Style |
| Feminine forms | Использование женских форм, если стиль поддерживает эту возможность |
| Avoid repeat | Не выбирать один и тот же стиль два раза подряд |

**Важно:** Random Style — самостоятельный плагин. Если одновременно включить его и другой плагин, который тоже изменяет исходящие сообщения, результат может зависеть от порядка их обработки. При тестировании лучше сначала включить только один обработчик сообщений.

Файл плагина: `random_style.plugin`.

Примерная структура основных файлов:

## ✦ Установка

**Требования:**
- Python 3.9 или новее.
- Telegram-аккаунт.
- API ID и API Hash.

### 01. Клонирование репозитория

```bash
git clone https://github.com/Begulabruh/Style-.git
cd Style-
pip install -r requirements.txt
```

### 02. Получение API ID и API Hash

1. Открой [my.telegram.org](https://my.telegram.org).
2. Войди по номеру телефона (код придёт в приложение Telegram).
3. Выбери **API development tools**.
4. Создай приложение (название любое, платформа Desktop).
5. Скопируй `api_id` и `api_hash`.

### 03. Настройка API

Открой `style_userbot.py` и впиши свои данные:

```python
API_ID = 12345678
API_HASH = "твой_api_hash"
```

Либо задай переменные окружения `API_ID` и `API_HASH`.

### 04. Настройка прокси (необязательно)

Если Telegram работает без прокси, ничего менять не нужно: оставь `PROXY_HOST` пустым, и скрипт подключится напрямую.

Для MTProto-прокси укажи:

```python
PROXY_HOST = "адрес_прокси"
PROXY_PORT = 443
PROXY_SECRET = "секрет_из_32_символов"
```

Эти значения тоже можно задать переменными окружения: `PROXY_HOST`, `PROXY_PORT`, `PROXY_SECRET`.

**Обрати внимание:**
- Секрет должен быть из 32 символов.
- Если он начинается с `dd`, убери эти две буквы.
- Fake-TLS секреты (начинаются с `ee`) в Telethon не поддерживаются.
- Для SOCKS5 нужен пакет `python-socks[asyncio]`.

### 05. Запуск

```bash
python style_userbot.py
```

При первом запуске введи **свой номер телефона**, а не токен бота, и код из Telegram.

В папке появится файл `style.session`.

## ✦ Вход по QR-коду

Если код из Telegram не приходит, можно использовать QR-авторизацию.

Установи зависимость:

```bash
pip install qrcode[pil]
```

Запусти:

```bash
python qr_login.py
```

Откроется изображение с QR-кодом.

На телефоне:

**Настройки → Устройства → Подключить устройство**

Наведи камеру на QR-код.

Скрипт использует настройки API и прокси из `style_userbot.py`.

## ✦ Частые проблемы

| Проблема | Решение |
|:--|:--|
| `Впиши свои API_ID и API_HASH` | Данные не вписаны или файл не сохранён |
| `TimeoutError` / `Server closed the connection` | Проверь подключение к Telegram и настройки сети или прокси |
| Команды ничего не делают | Убедись, что скрипт авторизован как пользователь, а не как бот |
| `database is locked` / `AuthKeyDuplicatedError` | Один файл `.session` используется несколькими запущенными скриптами. Не запускай одну сессию одновременно в нескольких процессах |
| `ModuleNotFoundError: style_core` | Проверь, что файлы лежат в одной папке и правильно названы |
| Код не приходит | Проверь чат «Telegram» внутри приложения или используй `qr_login.py` |

## ✦ Безопасность

> [!CAUTION]
> Файл `.session` предоставляет доступ к авторизованному Telegram-аккаунту. Не публикуй его и не передавай другим людям.

**Никогда не коммить:**
- `API_HASH`
- Файлы `*.session`
- Токены Telegram-ботов
- Секреты прокси
- QR-коды и коды авторизации

Перед публикацией проверь, что в файлах проекта стоят заглушки вместо личных данных.

Если токен или ключ попали в публичный репозиторий:
1. Пересоздай токен бота через `/revoke` в @BotFather.
2. Заверши подозрительные сессии через **Настройки → Устройства** в Telegram.
3. Не используй повторно скомпрометированные секреты.

Никому не отправляй QR-коды и коды входа.

## ✦ Настройка стилей

Основные фразы и вероятности находятся в `style_core.py`.

| Переменная | Назначение |
|:--|:--|
| `PRESETS` | Частота срабатывания эффектов (от 0 до 1) |
| `EMOTICONS` | Текстовые смайлики |
| `EMOJIS` | Эмодзи |
| `ACTIONS` | Действия |
| `FILLERS` | Дополнительные вставки |
| `SWAPS` | Основные замены слов |
| `GOPNIK_SWAPS` | Замены для гопник-стиля |
| `BUSINESS_SWAPS` | Замены для делового стиля |
| `FORMAL_SWAPS` | Замены для сверхофициального стиля |
| `UWU_SWAPS` | Замены для анимешного стиля |
| `GREMLIN_END` | Концовки хаотичного стиля |
| `STATIC_END` | Помехи в конце сообщения |
| `GLITCH_END` | Концовки глитч-стиля |
| `OLDPC_PREFIXES` | Приглашения командной строки |
| `YANDERE_END` | Концовки яндере-стиля |
| `TSUNDERE_END` | Концовки цундере-стиля |
| `DEPRESSIVE_END` | Концовки депрессивного стиля |

Вероятности в `PRESETS` задаются числами от `0` до `1`.
